# STC12C5A60S2 固件工程

完整中文说明、接线、协议和验收状态见 [仓库首页 README](../../README.md)。

- 内部 RC：22.1184 MHz；UART1 接主板，UART2 接上位机，两路均固定 115200、8 位数据、无校验、1 位停止位。
- START1～4 立即核对 X1～X4（P3.2～P3.5）；必须唯一为低且与命令一致才发送 `test\r\n`，否则立即 ERR。
- X5（P3.6）上电已低或每次从高变低时，取 X1～X4 唯一有效模号并启动；全高或多路低报 ERR。
- 活动会话持续检查锁定模号，断开、改号或多路低均主动报一次 ERR 并停测；接回不自动恢复。
- 每次有效 START 都可重新启动，不依赖 X5 或历史错误；START 来源会话不受 X5 释放影响。X5 来源会话在 X5 释放时正常停止、不报 ERR，之后可新 START 或重新有效拉低 X5 启动。
- X5 持低只启动一次，end 后仍监测该次模号；释放时取消对应待启动请求和监测。匹配 START／X5 同时到达时只启动一次，来源为 START。
- RD_NUM 根据当前输入回复 `{"Result":"x"}\r\n`（x 为 1～4），输入无效回复 ERR；查询不启动或改变会话。
- 启动后一直等待数据，不再使用输入或首帧超时。发送期间仍检测 X5；当前帧完整后报错或执行最新一次重触发，待报 ERR 优先。
- 每条主板记录上传一条 JSON；非空测量项仅保留首组，格式为 `测点=实测值 单位:结果`。
- Control 负责输入配置、快照和唯一模号识别；App 负责命令、触发、会话和转换；System 负责双串口，不再启用 Timer0 超时计时。
- Public_cfg.h 集中公共类型和存储区宏，board_config.h 保存时钟与容量配置；原厂 MCU 头文件保持不变。

打开 Project.uvproj，构建唯一目标 **828C Protocol Conversion Project**；EIDE 使用同名目标。内部 RC 在 STC-ISP 中设置，须与板级配置一致。

也可从仓库根目录执行：

```text
python "04 测试验证/build_keil.py"
python "04 测试验证/run_tests.py"
```

Keil 或构建脚本成功构建后，HEX 位于 Objects/Bridge828C.hex；EIDE 的输出根目录也为 Objects，构建器按目标建立子目录。构建和测试产物不上传 Git。旧固件、OBJ 和临时日志已清理，当前固件保留；下次编译会重新生成所需的中间文件。

本轮 180 项主机测试通过，Keil 与 µVision 零错误、零警告。X5、实时模号识别和当前输出格式仍待实板及真实上位机验收，详见 [程序编写验证记录](../../04%20测试验证/程序编写验证记录.md)。
