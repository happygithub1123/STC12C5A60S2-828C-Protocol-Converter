# 程序编写验证记录

## 验证口径

- 芯片：STC12C5A60S2，内部 RC 22.1184 MHz，双串口 115200、8N1。
- 原版本在该频率下的实物转换成功由使用者确认；本轮新增功能的实物验收不能据此替代。
- 主机测试编译同一份 App、Control、串口环形缓冲源码；串口收发、GPIO 寄存器和时间由模型提供，不模拟 8051 指令耗时。
- Keil 日志、HEX、DLL 和临时文件只保留本地，不纳入 Git；本记录维护验证结论。

## 第一阶段：X1～X4 低电平触发

- 新增 Control 输入驱动，P3.2～P3.5 准双向输入和弱上拉，保留端口其他位。
- START 后只检测对应输入，1000 ms 超时；999 ms 有效，1000 ms 超时优先。
- 触发仅发送 `test\r\n`，字节为 `74 65 73 74 0D 0A`；锁定模号且不重复触发。
- 验证其他输入为低不误触发、等待期间新 START 重置会话、旧主板数据及溢出丢弃、RD_NUM/OK 可处理、计时回绕、超时后恢复。
- 3 秒首条记录计时从 test 发送完成开始，输入等待时间不计入。
- 主机测试：65 项全部通过；此阶段保留原来的多值输出规则，作为下一阶段的对照。
- Keil：C51/A51/BL51/OH51 零错误、零警告。data=118 字节，xdata=882 字节，code=4735 字节，栈起始 0x75，上方可用 139 字节。
- 实板新增功能、波形和真实 828C 上位机：待验收。

- 验证长测点的流式输出、511/512 字节边界、多组后的连续帧同步、单位转义及非法编码。
- 主机测试：75 项全部通过。
