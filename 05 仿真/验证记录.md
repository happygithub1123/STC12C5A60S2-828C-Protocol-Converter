## Windows 启动入口

通过 `cmd.exe /d /c call .\启动仿真.cmd --no-open --port=8281`，在包含中文、全角括号和空格的本项目路径下启动。服务返回 HTTP 200，网页中文标题正确。脚本固定为 ASCII 内容和 CRLF，避免 Windows 批处理对多字节文本的解析问题；页面、Node.js 日志与说明均支持中文。

日常双击启动会自动打开浏览器，默认选取可用的本机端口。固定端口已被占用时会明确显示启动失败，不替换其他进程。
